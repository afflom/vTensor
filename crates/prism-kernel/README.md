# Prism-generated kernel model

`src/lib.rs` is synchronized from the Rust package generated by the vTensor
Prism app. The root `Justfile` runs that sync after a fresh proof, then records
the generated file's digest and Prism attestation in `prism-kernel.lock`.

The vTensor adapter uses the generated `supportsF64Matmul4` predicate before
delegating the fixed-shape matrix operation to Verdant Tensor. This package
contains no tensor arithmetic implementation. The crate manifest narrowly
allows `let_and_return` and `useless_asref`, patterns emitted by the generated
Rust code.
